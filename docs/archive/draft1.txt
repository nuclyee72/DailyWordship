워십 + 초성맞추기

게임판:
가로 10 x 세로 25 크기
가로 abcd…. 세로 각 플레이어마다 아래쪽 1 먼쪽 25
각 칸마다 쉬운 메이저 초성 대다수 + 마이너 초성 몇 개 8:2 비율 랜덤 배치


기물:
5길이x1 hp8
4길이x2 hp6
3길이x5 hp3


준비 페이즈
자신 앞 10x10타일 “정보 획득”
자신 앞 10x10에
준비된 배 놓기

“정보 획득”이란?
타일의 기본 상태는 모름(빈칸)
“정보 획득” 했을 경우 그 타일의 초성을 알아냄 + 상대 함선이 존재 할 경우 주황색 하이라이트, 주황색 하이라이트 된 타일은 상대에게도 표시(탐지 당함 표시)

*중요* 한 번 “정보 획득” 했더라도 
상대 함선이 존재하지 않을 수도 있음, 그 경우 새로 “정보 획득” 할 때 하이라이트 표시되고 없어짐(?) 표시

배틀 페이즈
행동 리스트:
이동:
자신의 함선 선택 -> 그 함선으로부터 1칸 이내의 타일이 포함되는 모든 칸이 “정보 획득” 상태인 3~5 길이의 단어 박스 선택 후 사용 -> 함선 이동(같은 함선 ID, 위치 이동) -> 이동 후 그 함선으로부터 1칸 이내의 타일의 “정보 획득”

탐지:
자신의 함선이 포함된 타일 선택 -> 방향 선택 후 사용 -> 그 타일로부터 선택한 방향으로 5칸의 “정보 획득”

식별:
자신의 함선으로부터 7칸 이내의 타일이 포함되는 3~5 길이의 단어 박스 선택 후 사용 -> 단어 추측 -> 함선이 존재할 경우 “식별당함” 효과 부여, 타일의 글자가 일치할 경우 “정보 획득+”(해당 글자를 알아냄(만약 이동할 경우 다시 초성만 나오는 “정보 획득” 상태로))

“식별당함”이란?
식별당한 함선은 이동 불가
입는 피해 3배

포격: 
자신의 함선으로부터 n칸 이내의 타일 선택 -> 포격 사용 -> 해당 칸에 데미지 1, 만약 피격당한 함선이 체력이 0 이하가 되었다면 “침몰”함
n은 함선의 길이에 따라 달라짐
포격 시 상대에게 포격한 함선의 타일 중 상대에게 주황색으로 표시되지 않은 타일 중 랜덤으로 하나 표시됨

“침몰” 이란?
해당 칸의 글자 밝혀짐, 글자 고정됨, 이미 배가 있는 칸으로는 판별되지 않음

ex) 별바다 라는 글자의 함선이 침몰함 -> 다른 함선이 ‘다’자를 이용하여 다슬기 단어를 사용하여 이동 가능, 하지만 ‘ㄷ’를 이용한 도시락은 불가능, 무조건 다 자를 써야함
