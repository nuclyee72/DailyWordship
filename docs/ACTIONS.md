# WordShip 행동 레퍼런스

4개 행동의 **조작 흐름 · 전제 조건 · 효과**를 전부 적는다.
기획 의도는 [GDD.md](GDD.md), 구현은 `prototype/src/game.js`.

---

## 0. 공통 규칙

### 0.1 거리는 유클리드(직선 거리) **[v0.6]**

```js
dist(A, B) = √((A.x − B.x)² + (A.y − B.y)²)
```

- 대각선은 √2 ≈ **1.414**. 직선 1칸보다 멀다.
- **함선과 칸의 거리 = 함선이 점유한 타일 중 가장 가까운 것까지의 거리.** 중심이나 머리가 아니다.
- 범위 판정은 제곱끼리 비교해 부동소수점 오차를 피한다 (`dx² + dy² ≤ r²`).

이 때문에 사거리 범위는 **사각형이 아니라 원형**이다. 대각 구석이 잘린다.

```
3칸 함선 포격(r=3) 실제 도달 칸 수

   체비쇼프(구)  9×7 사각형 = 63칸
   유클리드(신)  원형        = 43칸      ← 32% 감소
```

| 범위 | 도달 칸 수 (보드 중앙 기준) |
|---|---|
| 3칸함 포격 r=3 | 43칸 |
| 4칸함 포격 r=5 | 96칸 |
| 식별 r=7 | 134칸 |
| 이동 인접 r=1.5 | 15칸 (8방향 유지) |

> **이동 인접만 1.5인 이유** — "1칸 이내"는 사거리가 아니라 *맞닿음*이다. √2 < 1.5 이므로 **대각선도 인접으로 인정**되어 기존 8방향 그대로다. 정확히 1.0으로 두면 상하좌우 4방향만 남아 이동이 크게 제약된다. `BALANCE.move.adjacency` 로 바꿀 수 있다.

### 0.2 모든 행동이 먼저 통과해야 하는 관문

순서대로 검사하고, 걸리는 즉시 거부한다. **거부되면 AP도 쿨타임도 소모되지 않는다.**

| # | 검사 | 실패 메시지 |
|---|---|---|
| 1 | 전투 페이즈인가 | `전투 중이 아님` |
| 2 | AP가 비용 이상인가 | `AP 부족 (n 보유 / m 필요)` |
| 3 | 그 함선이 내 것이고 살아 있는가 | `자기 함선이 아님` / `침몰한 함선` |
| 4 | 그 함선의 쿨타임이 끝났는가 | `쿨타임 n초 남음` |

AP는 **진영 공유 자원**(2.5초당 1, 최대 10), 쿨타임은 **함선 개별**이다. 둘 중 하나만 막혀도 행동할 수 없다.

### 0.3 비용표

| 행동 | AP | 쿨타임 | 사거리 |
|---|---|---|---|
| 이동 | **3** | 함선 길이 × 3초 (3칸 9s / 4칸 12s) | 인접 1.5 |
| 탐지 | 1 | 5초 | 직선 5칸 (거리 무관) |
| 식별 | 2 | 8초 | 7 |
| 포격 | 1 | 6초 | 3칸함 3 / 4칸함 5 |

### 0.4 공통 조작

| | |
|---|---|
| 함선 선택 | 보드에서 아군 함선 클릭 · 함대 목록 클릭 · `Tab` 순환 |
| 행동 선택 | `1` 이동 · `2` 탐지 · `3` 식별 · `4` 포격 |
| 취소 | `Esc` |
| 초록 칸 | 지금 누를 수 있는 곳 |
| 파란 칸 | 선택한 행동의 사거리 |
| 흐린 버튼 | 지금 불가. 눌러 보면 이유를 알려준다 |

## 1. 이동 — 3 AP

> 한 줄: **새 단어를 밟고 그 단어를 이름으로 삼는다.** 기동·정찰·은폐가 한 번에 일어난다.

### 1.1 조작 흐름

```
함선 선택
   ↓
[1] 또는 「이동」 버튼
   ↓  보드에 초록 칸 표시 = 합법 박스의 양 끝
박스 시작 칸 클릭
   ↓  초록이 좁혀짐 = 그 칸과 짝이 되는 반대쪽 끝
박스 끝 칸 클릭
   ↓  입력창에 추천 단어가 회색으로 뜸 · 자동 포커스
단어 입력 → Enter
   (빈칸으로 Enter = 추천 단어 사용)
```

박스는 **가로 또는 세로 직선**이며 길이는 **함선 길이와 같아야** 한다(3칸함 = 3글자). 읽는 방향은 4방향 모두 가능하다.

### 1.2 전제 조건 (검사 순서)

| # | 조건 | 실패 시 |
|---|---|---|
| 1 | 공통 관문 §0.2 | |
| 2 | 함선이 `식별당함` 상태가 아닐 것 | `식별당함 — 이동 불가 (해제 수단 없음)` |
| 3 | 박스 길이 = 함선 길이 | `단어 박스 길이가 함선 길이와 달라야 함` |
| 4 | 직선 연속 칸일 것 | `직선 연속 박스가 아님` |
| 5 | **지금 있는 칸 집합과 다를 것** (뒤집기 포함) | `자기 자리로는 이동할 수 없음` |
| 6 | 박스의 **모든** 칸이 초성 판명 상태 | `초성 미판명 칸 포함: e14` |
| 7 | 박스 중 최소 1칸이 함선으로부터 거리 ≤ 1.5 | `현재 위치로부터 1칸 이내의 칸을 포함해야 함` |
| 8 | 단어 판정 통과 (§1.5) | 사유별 메시지 |
| 9 | 아군 함선과 겹치지 않을 것 | `아군 함선과 겹침` |

### 1.3 실행 효과 (순서대로)

```
1. AP −3, 쿨타임 = 함선 길이 × 3초
2. 옛 칸 점유 해제 → 새 칸 점유
3. 함명 = 입력한 단어                     ← 핵심
4. 상대가 이 함선에 대해 해독한 음절 전부 삭제
5. 함선 타일 + 반지름 1.5 이내 전부 정보 획득
     · 초성 판명 (영구)
     · 적함이 있으면 접촉(주황) — 상대에게도 피탐으로 기록
     · 전에 접촉이었는데 비어 있으면 이탈(?)
6. 상륙 판정 — 타일 하나라도 자기 기준 25행이면 즉시 승리
```

3칸 함선이 이동하면 **15칸**이 한 번에 밝혀진다 (5×3).

### 1.4 특수: 적함과 충돌

모르고 적함 위로 이동을 시도할 수 있다.

```
이동 실패 · AP 3 소모 · 쿨타임 걸림 · 함명 그대로
충돌한 칸에 접촉(주황) 부여
```

턴을 잃는 대신 위치 정보를 얻는다. "들이받아서 찾았다".

### 1.5 단어 판정 파이프라인

```
① 길이     단어 글자 수 = 박스 칸 수
② 문자     완성형 한글만
③ 칸별 대조  잔해 칸  → 각인된 음절과 정확히 일치
            그 외    → 초성만 일치
④ 사전     등재어인가
```

경음은 대체 불가. 타일이 `ㄲ`이면 단어도 `ㄲ`이어야 한다.

### 1.6 전략 메모

이동은 **세 가지를 한꺼번에 사는** 행동이라 3 AP다.

| 측면 | 효과 |
|---|---|
| 기동 | 위치 이동 + 상륙 진척 |
| 정찰 | 주변 15칸 자동 판명 → 다음 이동의 연료 |
| **은폐** | 함명 교체 → 상대의 해독 정보가 통째로 무효 |

움직이려면 목적지 초성을 알아야 하고, 초성을 알려면 탐지하거나 이동해야 한다. 이 순환이 게임의 엔진이다.

## 2. 탐지 — 1 AP

> 한 줄: **한 방향으로 5칸을 밝힌다.** 가장 싸고, 가장 안전하고, 가장 좁다.

### 2.1 조작 흐름

```
함선 선택
   ↓
[2] 또는 「탐지」 버튼
   ↓  방향 패드가 나타남
방향 버튼 클릭  →  즉시 실행
```

**단 두 번이면 끝난다.** 보드 클릭이 필요 없다.

- 방향 8개: `↖ ↑ ↗ ← → ↙ ↓ ↘`
- 단축키: `W`(북) `S`(남) `A`(서) `D`(동) `Q`(북서) `E`(북동) `Z`(남서) `C`(남동)

### 2.2 발사 원점은 자동으로 잡는다

플레이어가 타일을 고르지 않는다. 엔진이 **그 방향으로 가장 앞선 자기 타일**을 고른다.

```
3칸 함선이 세로로 (e5, e6, e7) 에 있고 북쪽 탐지
  → 원점 = e7 (가장 북쪽)
  → e8 ~ e12 판명
```

어차피 플레이어가 원하는 건 사거리를 제일 멀리 뽑는 칸이므로, 고르게 할 이유가 없다.

### 2.3 전제 조건

| # | 조건 | 실패 시 |
|---|---|---|
| 1 | 공통 관문 §0.2 | |
| 2 | 유효한 방향 | `방향 오류` |

이동과 달리 **식별당한 함선도 탐지할 수 있다.** 묶인 배가 할 수 있는 몇 안 되는 일이다.

### 2.4 실행 효과

```
1. AP −1, 쿨타임 5초
2. 원점의 다음 칸부터 그 방향으로 연속 5칸:
     · 초성 판명 (영구)
     · 적함이 있으면 접촉(주황) + 상대에게 피탐 기록
     · 전에 접촉이었는데 비어 있으면 이탈(?)
3. 보드 밖으로 나가면 거기서 중단 — 남은 사거리는 버려진다
```

보드 가장자리에서 바깥을 향해 쏘면 손해다. 위 예시에서 e23에서 북쪽으로 쏘면 e24 한 칸만 얻는다.

### 2.5 전략 메모

- **직선 1줄만** 열린다. 이동(15칸)의 1/3이다. 대신 1 AP.
- 위치가 노출되지 않는다. 포격과 달리 반동이 없다.
- 쿨타임 5초로 가장 짧아 연타하기 좋다.
- 이동할 길을 뚫는 용도다 — 이동은 목적지 **전부**가 판명돼야 하므로, 전진하려면 먼저 탐지해야 한다.

## 3. 식별 — 2 AP

> 한 줄: **적 함명을 추리해서 맞힌다.** 성공하면 그 배는 영원히 못 움직인다.
> 이 게임에서 가장 언어적이고 가장 무거운 행동.

### 3.1 조작 흐름

```
함선 선택
   ↓
[3] 또는 「식별」 버튼
   ↓  파란 범위 = 거리 7 이내 + 초성 판명된 칸
박스 시작 칸 클릭
   ↓  초록 = 3~4칸 박스가 성립하는 반대쪽 끝
박스 끝 칸 클릭
   ↓
적 함명을 추측해 입력 → Enter
```

박스 길이는 **3~4칸**이며, 내 함선 길이와 무관하다.

### 3.2 무엇을 추측하는가

적 함선은 **마지막으로 이동할 때 쓴 단어**를 이름으로 지니고 있다. 그 단어를 맞히는 것이다.

```
적함이 (c8, c9, c10) 을 차지하고 함명이 「바다새」라면
  → 그 칸들의 초성은 ㅂ ㄷ ㅅ
  → 내가 「바다새」라고 입력하면 3칸 전부 해독
  → 「바람새」라고 입력하면 '바'와 '새' 2칸만 해독
```

**칸별 독립 판정**이라 부분 적중이 쌓인다.

### 3.3 전제 조건

| # | 조건 | 실패 시 |
|---|---|---|
| 1 | 공통 관문 §0.2 | |
| 2 | 박스 길이 3~4칸 | `식별 박스는 3~4칸` |
| 3 | 직선 연속 | `직선 연속 박스가 아님` |
| 4 | 모든 칸이 초성 판명 | `초성 미판명 칸 포함` |
| 5 | 모든 칸이 내 함선으로부터 거리 ≤ 7 | `사거리 초과 — f12 (최대 7칸)` |
| 6 | 단어 판정 통과 (§1.5) | 사유별 메시지 |

### 3.4 실행 효과 — 세 가지가 독립적으로 일어난다

```
AP −2, 쿨타임 8초

① 함선 판정
   박스 안에 적함이 있으면 → 그 함선 전부에 「식별당함」
     · 이동 영구 불가 (해제 수단 없음)
     · 입는 피해 3배
     · 양측 화면에 적색 ✕
   적함이 없으면 → 아무 일도 없음 (AP만 소모)

② 음절 판정 — 칸마다 따로
   for 각 칸:
     적함이 있고 && 입력 음절 == 그 칸의 함명 음절
       → 그 음절 해독 (내 지식에만 기록)
   전 음절을 해독하면 → 그 함선의 실루엣 전체 공개
                        (길이·방향·위치가 확정된다)

③ 접촉 확정
   적함 있는 칸 → 접촉(주황) + 상대에게 피탐
   빈 칸        → 빈 칸으로 확정
```

### 3.5 해독한 정보는 휘발성이다

| 상황 | 해독 정보 |
|---|---|
| 대상 함선이 **이동** | **전부 소멸** — 새 단어를 쓰니 이름이 바뀐다 |
| 대상 함선이 **침몰** | 잔해 각인으로 승격 (영구·양측 공개) |
| 그 외 | 유지 |

**단, 식별당한 배는 이동할 수 없다.** 그래서 한 번 식별에 성공하면 해독 정보가 그 배가 죽을 때까지 유효하다. 디버프와 정보가 서로를 잠근다.

### 3.6 전략 메모

식별은 문 두 개를 동시에 연다.

1. **묶는다** — 이동 불가. 상륙 돌파는 그 순간 끝난다
2. **보이게 한다** — 식별당한 함선만 체력 바와 피해량이 보인다 (§4.5)

2 AP의 값이 여기서 나온다. 추리 난이도는 사전이 결정한다 — 초성 `ㅂㄷㅅ`에 맞는 3글자 명사가 몇 개인지가 곧 적중률이다.

> **[우려]** 해제 수단이 없어 매우 강력하다. 특히 상륙 돌파와 정면으로 충돌한다 — 돌파 주자가 적진에서 한 번 식별당하면 영영 멈추고, 상대는 천천히 잡으면 된다. 방어가 공격을 압도할 수 있다. 밸런스 단계의 관측 대상이다. (GDD §8.1)

## 4. 포격 — 1 AP

> 한 줄: **한 칸을 때린다.** 대신 반드시 내 위치가 하나 드러난다.

### 4.1 조작 흐름

```
함선 선택
   ↓
[4] 또는 「포격」 버튼
   ↓  파란 범위 = 사거리 안
목표 칸 클릭  →  즉시 발사
```

### 4.2 전제 조건

| # | 조건 | 실패 시 |
|---|---|---|
| 1 | 공통 관문 §0.2 | |
| 2 | 목표가 사거리 안 (3칸함 3 / 4칸함 5) | `사거리 초과 (길이 3 → 3칸)` |
| 3 | 아군 함선이 아닐 것 | `아군 함선은 조준 불가` |

**목표 칸이 미탐색이어도 쏠 수 있다.** 맹목 사격이 허용된다.

### 4.3 피해 계산

```
dmg = 1
if (그 칸의 음절을 내가 안다)   dmg += 1     ← 정밀 사격
if (피격 함선이 식별당함)       dmg *= 3
```

곱셈이 바깥이라 조합이 크게 보상받는다.

| 상황 | 피해 |
|---|---|
| 맹목 사격 | 1 |
| 음절 해독한 칸 / 잔해 칸 | 2 |
| 식별당한 함선 | 3 |
| **식별 + 해독** | **6** |

3칸 함선(HP 3)은 식별당한 상태에서 정밀 포격 **한 방**에 침몰한다.

"그 칸의 음절을 안다" = 식별로 해독했거나, 잔해 칸이거나. 잔해는 항상 공개이므로 **잔해 지대는 영구 +1 피해 구역**이다.

### 4.4 실행 효과

```
AP −1, 쿨타임 6초

명중  → HP 감소, 그 칸 접촉(주황) 확정 (양측)
빗나감 → 그 칸 빈 칸으로 확정
HP ≤ 0 → 침몰 (§4.6)

반동 (명중·빗나감 무관)
  내 함선 타일 중 상대에게 아직 노출 안 된 칸 하나를
  랜덤으로 골라 상대에게 공개한다.
  전부 노출된 상태면 아무 일도 없다.
```

### 4.5 무엇이 보이는가 — 식별 여부가 갈랐다

| 대상 | 사수가 보는 것 |
|---|---|
| 식별하지 않은 적함 | **"명중" 만.** 피해량도 HP도 안 보임 |
| **식별당한** 적함 | 피해량 + 체력 바 |
| 자기 함선 | 항상 전부 |

몇 대 때렸는지 모르면 언제 죽일 수 있는지도 모른다. 그래서 **맹목 포격만으로는 적을 계획적으로 갉아먹을 수 없다.** 죽이려면 먼저 식별해야 한다.

다만 명중하면 그 칸에 적함이 있다는 것은 알게 되므로, **정찰 수단으로는 여전히 쓸 수 있다.**

### 4.6 침몰

```
그 함선의 함명이 점유 타일에 그대로 각인된다.

for 각 타일:
  잔해로 전환 (영구·양측 공개)
  점유 해제 — 더 이상 함선으로 판별되지 않는다
  양측 초성 판명 + 접촉 해제
```

잔해 칸의 성질:

| 항목 | 내용 |
|---|---|
| 글자 | **영구 고정.** 그 칸을 지나는 모든 단어가 **정확한 음절**을 써야 한다 |
| 통과 | 가능. 함선이 올라설 수 있다 |
| 표적 | 아님. 식별·포격 대상이 되지 않는다 |
| 포격 | 음절이 공개 상태라 항상 정밀(+1) |

```
함명 「별바다」 함선 침몰 → 별 / 바 / 다 각인
다른 함선이 '다' 칸을 지나려면
    다슬기  가능   ('다' 일치)
    도시락  불가   (ㄷ만 맞고 '다'가 아님)
```

침몰이 쌓일수록 보드가 딱딱해진다. 항로가 좁아지고, 잔해 지대는 피해 +1 구역이 된다. **침몰지가 위험지대로 변해 전장을 재편한다.**

### 4.7 전략 메모

- **쏘면 들킨다.** 반동은 명중 여부와 무관하다. 빗나간 사격은 순손실이다.
- 4칸함(사거리 5)은 같은 행에서는 보드 폭 전체를 덮지만, 세로로는 5칸까지다.
- 쿨타임 6초라 연타는 어렵다. 3칸함 하나를 확실히 잡으려면 식별 후 정밀 한 방이 낫다.

## 5. 한눈에 비교

| | 이동 | 탐지 | 식별 | 포격 |
|---|---|---|---|---|
| AP | 3 | 1 | 2 | 1 |
| 쿨타임 | 9~12초 | 5초 | 8초 | 6초 |
| 사거리 | 인접 1.5 | 직선 5칸 | 7 | 3 / 5 |
| 단어 필요 | 예 (함선 길이) | 아니오 | 예 (3~4글자) | 아니오 |
| 조작 횟수 | 4 (함선·행동·칸2) + 단어 | **2** (함선·방향) | 4 + 단어 | 3 |
| 내 위치 노출 | 아니오 | 아니오 | 아니오 | **예 (반동)** |
| 식별당해도 가능 | **아니오** | 예 | 예 | 예 |
| 정보 획득 | 15칸 초성 | 5칸 초성 | 접촉 확정 + 음절 | 접촉 1칸 |
| 주 효과 | 이동·은폐 | 초성 확보 | 영구 이동 봉쇄 | 피해 |

### 행동 사이의 의존 관계

```
탐지 ──초성──→ 이동 ──전진──→ 상륙 승리
                 │
                 └─접촉─→ 식별 ──봉쇄·해독──→ 포격 ──→ 침몰 ──→ 전멸 승리
                                                          │
                                                          └─→ 잔해(지형 변화)
```

- 이동하려면 **먼저 탐지**해야 한다 (목적지 전부가 판명돼야 함)
- 식별하려면 **먼저 접촉**이 있어야 유용하다 (없으면 AP만 날린다)
- 효율적으로 죽이려면 **먼저 식별**해야 한다 (피해 3배 + 체력이 보임)
